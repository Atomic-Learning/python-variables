In Python, a variable is the name used in source code to a storage location in the computer's memory. We can create a variable by writing the name of the variable followed by an equals sign (=) and then the value we want to store in that variable. If we use the variable name later in our code, Python will replace it with the value we assigned to it. In the example below, we create a variable called age and assign it the value 25. When we place a variable in the parentheses on a call to the print function the value of variable is returned. Here, printing the value of age outputs 25. age = 25 print(age)

Variable Naming Rules

When naming variables in Python, there are a few important rules to follow:
  • Variable names can only contain letters (a-z, A-Z), numbers (0-9), and underscores (_).
  • Variable names cannot start with a number. For example, 1st_place is not a valid variable name.
  • Variable names are case-sensitive. This means that age, Age, and AGE are considered different variables.
In addition, variables may not use Python reserved words (keywords), as these have special meanings in the language. These values are:

Variable Name Clashes

Although the prohibition of reserved words helps avoid some naming conflicts, it is still possible to accidentally overwrite important built-in functions or modules by using the same name for a variable. For example, if we create a variable called print, our variable will hide (or "shadow") the built-in print function, and we will no longer be able to use it until we delete our variable. For example, the code cell below shows what happens when we create a variable called print and then try to use the print function. print = 5 # This creates a variable called 'print' print(10) # This will cause an error You should have seen an error message indicating that a int object is not callable. This is because Python is trying to call our variable print (which is a integer) as if it were a function, instead of the built-in print function. To avoid such issues, it is a good practice to choose variable names that are unlikely to clash with built-in names.

Variables and expressions

If the code on the right-hand side of the assignment operator is an expression, Python will first evaluate the expression and then assign the resulting value to the variable. For example, in the code below, we create a variable called x and assign it the result of the expression 5 + 3. Python evaluates the expression to get 8, and then assigns that value to x. When we print the value of x, Python outputs 8. x = 5 + 3 print(x)
